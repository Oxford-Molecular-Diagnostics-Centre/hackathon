# Oxford Cancer AI Challenges

A static PI discussion draft: identify clinical research challenges with researchers and clinicians; match suitable biological, experimental and computing resources; then invite the AI community after review and agreement.

Run locally from this directory:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. GitHub Pages can serve this folder without a build step.

The page keeps the existing Oxford branding, typography, responsive sections, research examples, data-access explanations and participation/IP guidance. `visuals.css` adds the visual layer. Local assets and their creation record, including the complete image-generation prompt, are in `assets/illustrations/README.txt`.

The cancer vaccine example is a proposed challenge family with possible melanoma, lung, colorectal and other cancer-specific briefs. Each would need its own owner, evidence, permissions and evaluation. CEDAR is linked as a candidate public resource, not a confirmed challenge dataset. Peptide presentation, T-cell recognition and clinical benefit remain distinct endpoints.

The proposal form prepares, copies and downloads a local draft. Online collection is disabled by default. Its configuration requires an approved submission route and privacy notice before activation. No sample access, assays, compute, funding, prizes or partnerships are committed.

The page remains `noindex` for review but is publicly reachable if hosted. It is not a private or access-controlled channel. Organisational branding, research-proposal permissions, governance review and approved submission/privacy arrangements remain conditions for public launch. No deployment or hosting change is included in this local update.
